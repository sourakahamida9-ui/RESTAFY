SYSTÈME DE GÉNÉRALISATION DES MENUS RESTAURANTS - RÉSUMÉ
=========================================================

OBJECTIF
--------
Permettre aux restaurants de dupliquer, importer, exporter et sauvegarder leurs menus.

FONCTIONNALITÉS CRÉÉES
----------------------

1. DUPLIQUER (Duplicate Menu)
   ✓ Copie un menu d'un restaurant à un autre
   ✓ Options: Inclure variantes, Multiplicateur de prix
   ✓ Traçage avec menu_imports table

2. SAUVEGARDER (Save Snapshot)
   ✓ Crée une sauvegarde versionnée du menu
   ✓ Stocke catégories, items, variantes en JSONB
   ✓ Max 50 snapshots par restaurant

3. RESTAURER (Restore Snapshot)
   ✓ Retrouve un menu à partir d'une sauvegarde
   ✓ Remplace complètement le menu actuel
   ✓ Avec confirmation pour éviter erreurs

4. EXPORTER (Export JSON)
   ✓ Télécharge le menu en JSON
   ✓ Format versionné et standardisé
   ✓ Backup hors-ligne du menu

5. IMPORTER (Import JSON)
   ✓ Importe un menu depuis JSON
   ✓ Options: Variantes, Prix, Préfixes noms
   ✓ Validation et limitation à 1000 articles

--------------------------

Rôles: restaurant_owner, manager, staff

BASES DE DONNÉES - TABLES CRÉÉES
---------------------------------

1. menu_snapshots
   Columns: id, restaurant_id, snapshot_name, categories_data (JSONB),
            items_data (JSONB), variants_data (JSONB), notes, created_at, created_by
   RLS: restaurant_owner full access, super_admin full access

2. menu_imports
   Columns: id, restaurant_id, source_restaurant_id, import_type, status,
            total_items, imported_items, error_message, created_at, created_by
   RLS: restaurant_owner can read/write own

3. menu_templates
   Columns: id, name, cuisine_type, preview_data (JSONB), is_global, created_by
   RLS: global read, admin only creation

4. items - Colonnes ajoutées
   - source_restaurant_id (FK)
   - is_template (BOOLEAN)
   - template_tags (JSONB)
