FONCTIONNALITES IMPLEMENTEES:

1. NOTIFICATIONS SONORES
   - Son de beep lors d'une nouvelle commande
   - Utilise Web Audio API (pas de fichiers audio necessaires)
   - 2 tons differents pour attirer l'attention

2. NOTIFICATIONS PUSH (Browser)
   - Demande de permission automatique
   - Notification native du navigateur
   - Affiche: numero commande + montant

3. ALERTE VISUELLE (Dashboard)
   - Banniere verte animee en haut de l'ecran
   - Affiche pendant 5 secondes
   - Bouton pour fermer manuellement

4. CENTRE DE NOTIFICATIONS (Bell Icon)
   - Dropdown avec liste des notifications
   - Badge avec nombre non-lus
   - Marquer comme lu au clic
   - "Tout marquer lu" en un clic
   - Temps relatif (Il y a 5 min, etc.)

5. NOTIFICATIONS EN BASE DE DONNEES
   - Table `notifications` avec RLS
   - Trigger automatique sur nouvelle commande
   - Trigger automatique sur changement de statut
   - Real-time via Supabase subscriptions
