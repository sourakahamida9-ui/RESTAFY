🔴 PROBLÈME 1: ANALYTICS STATIQUE (IMPACTUAL: MOYENNE)
────────────────────────────────────────────────────────
Symptôme:     Données en dur dans Analytics.tsx, pas de données réelles
Cause:        Pas de hook de data fetching, données hardcodées
Fichier:      src/pages/admin/Analytics.tsx
Solution:     Créer useAnalyticsData.ts pour charger les données de Supabase
Impact:       Les restaurants verront leurs vraies données en temps réel
Priorité:     ⭐ MOYENNE
Complexité:   Facile (4-6 heures)
Fichiers:     +1 hook, +1 modification


🔴 PROBLÈME 2: FORMAT USSD NON MODIFIABLE (IMPACT: MEDIUM)
────────────────────────────────────────────────────────────
Symptôme:     Format fixe *880*CODE*MONTANT# , pas d'option pour changer
Cause:        Format hardcodé dans le code, pas de config en BD
Fichier:      src/pages/admin/Settings.tsx, payment_methods table
Solution:     Ajouter colonne ussd_template + UI pour modifier + migration SQL
Impact:       Restaurants peuvent adapter leurs codes USSD à leurs besoins
Priorité:     ⭐⭐ MOYEN-IMPORTANT
Complexité:   Facile (6-8 heures)
Fichiers:     +1 migration SQL, +1 section UI, +1 hook


🔴 PROBLÈME 3: RESTAURANTS NE CRÉENT PAS DE COMPTES/MENUS (IMPACT: CRITIQUE)
───────────────────────────────────────────────────────────────────────────────
Symptôme:     Pas d'interface pour créer restaurant, pas d'option menu
Cause:        Pages/formulaires manquants, RLS confuses, pas d'onboarding
Fichiers:     Multiples pages + RLS
Solution:     Créer RestaurantSetup.tsx + MenuManager.tsx + fix RLS
Impact:       Les restaurants peuvent enfin créer leurs comptes et menus
Priorité:     ⭐⭐⭐ CRITIQUE
Complexité:   Moyen (1-2 jours)
Fichiers:     +2 pages, +1 migration SQL, +3 modifications


🔴 PROBLÈME 4: CODES PROMO NE FONCTIONNENT PAS (IMPACT: CRITIQUE)
──────────────────────────────────────────────────────────────────
Symptôme:     Codes créés mais pas appliqués au panier, pas de réduction
Cause:        Pas d'input promo dans Cart, pas de logique d'application
Fichiers:     src/pages/Cart.tsx, src/hooks/useOrderManager.ts
Solution:     Ajouter section promo + logique de validation + intégration commande
Impact:       Les codes promo enfin fonctionnels, augmente les conversions
Priorité:     ⭐⭐⭐ CRITIQUE
Complexité:   Moyen (1-2 jours)
Fichiers:     +1 modification Cart, +1 modification hook


🔴 PROBLÈME 5: ÉQUIPE - CHAMPS MANQUANTS NON AFFICHÉS (IMPACT: CRITIQUE)
──────────────────────────────────────────────────────────────────────────
Symptôme:     "Champs manquants" erreur mais aucun champ à remplir
Cause:        Formulaire incomplet, validation stricte, champs cachés
Fichier:      À créer - TeamManager.tsx
Solution:     Créer formulaire complet avec horaires conditionnels
Impact:       Les restaurants peuvent créer une équipe sans confusion
Priorité:     ⭐⭐⭐ CRITIQUE
Complexité:   Moyen (1 jour)
Fichiers:     +1 page, +1 migration SQL

  RISQUES & MITIGATION

  Mitigation: Ajouter indexes SQL, caching SWR

  Mitigation: Messages d'erreur clairs par champ
