🎯 5 FONCTIONNALITÉS IMPLÉMENTÉES
---------------------------------

1. DUPLIQUER (Duplicate Menu)
   ✓ Copie menu restaurant A → restaurant B
   ✓ Options: Inclure variantes, Ajuster prix
   ✓ Exemple: Restaurant franchise duplicateur

2. SAUVEGARDER (Save Snapshot)
   ✓ Crée une version du menu (JSONB)
   ✓ Max 50 par restaurant
   ✓ Exemple: Avant/après changement menu

3. RESTAURER (Restore Snapshot)
   ✓ Retrouve menu ancien
   ✓ Avec confirmation
   ✓ Exemple: Undo un changement accidentel

4. EXPORTER (Export as JSON)
   ✓ Télécharge menu en JSON
   ✓ Backup hors-ligne
   ✓ Exemple: Sauvegarde locale

5. IMPORTER (Import from JSON)
   ✓ Importe JSON dans menu
   ✓ Options prix/variantes
   ✓ Exemple: Partage entre restaurants
