# Marketing et communication — Restafy

Guide opérationnel pour **structurer** le marketing, **prioriser** les actions et **préparer les livrables** sans se disperser. Complète la section *Voix et communication* du [README](../README.md).

---

## 1. Comment « gérer » le marketing au quotidien

### Principe

Le marketing Restafy sert **trois publics** en parallèle (avec des messages différents) :

| Public | Objectif principal | Indicateur utile |
|--------|-------------------|------------------|
| **Convives** (clients finaux) | Télécharger / commander / revenir | Inscriptions, commandes, rétention |
| **Restaurants** (partenaires) | Rejoindre la plateforme, rester actifs | Inscriptions pro, menus à jour, CA traité |
| **Presse / institutions / sponsors** (optionnel) | Crédibilité, visibilité | Mentions, partenariats |

Évitez un seul discours « fourre-tout » : adaptez l’accroche (B2C vs B2B).

### Organisation légère (recommandée)

1. **Un responsable marketing** (même à mi-temps) : calendrier, validation des textes, lien avec le produit.
2. **Un canal unique de vérité** : Notion, Google Drive ou dossier `docs/` + tableur pour le calendrier éditorial.
3. **Rythme fixe** : par ex. 1 réunion courte / semaine « qu’est-ce qu’on publie ? » + revue mensuelle des chiffres.
4. **Stack outils** (au choix) :
   - **Design** : Figma ou Canva (templates Restafy réutilisables).
   - **Réseaux** : Meta Business Suite, éventuellement Buffer / Later pour planifier.
   - **E-mail** : Brevo / Resend (déjà dans l’écosystème projet) pour newsletters et relances pros.
   - **Analytique** : Vercel Analytics + événements produit (si vous les tracez) + retours restaurants.

### Piliers de contenu (à tourner)

- **Utile** : « Comment commander », « Modes de livraison », FAQ.
- **Preuve** : témoignages restaurants, chiffres réels (sans surpromesse).
- **Territoire** : ancrage Bénin / Afrique de l’Ouest, événements locaux.
- **Produit** : nouveautés (fidélité, événements, caisse, etc.) — toujours en français clair.

### Budget (même minimal)

Répartissez **temps** et **petit budget** entre : création (design, rédaction), ads test (petites campagnes géolocalisées), et **relations** (échantillons, partenariats avec 2–3 restaurants pilotes).

## 2. Livrables à préparer — checklist communication

Cochez au fur et à mesure. Priorité suggérée : **fondations → digital → partenaires → lancement**.

### A. Fondations marque (indispensable)

- [ ] **Positionnement** : une phrase « nous sommes… pour… » + 3 preuves (ex. menus réels, multi-modes, fidélité).
- [ ] **Baseline** : *Ne mangez pas. Savourez.* — usages prévus (site, signature) documentés.
- [ ] **Palette + typo** : couleurs officielles (orange Restafy, neutres), polices web (cohérentes avec l’app).
- [ ] **Logo** : versions PNG/SVG (clair, sombre, favicon, réseaux).
- [ ] **Charte rédactionnelle** : ton (voir README), mots à éviter (ex. promesses de délais non garantis), glossaire (FCFA, livraison, sur place, etc.).

### B. Site et présence en ligne

- [ ] **Page d’accueil** : message à jour, CTA clair (télécharger / commander / proposer son restaurant).
- [ ] **Pages légales** : mentions, confidentialité, CGU / CGV si vous encaissez côté plateforme (à valider juridiquement).
- [ ] **Fiche Google Business** (si entité locale) + **réseaux** : au moins un canal tenu régulièrement (souvent Instagram ou Facebook au Bénin).
- [ ] **Lien unique** type `restafy.bj` ou domaine final + **QR** pour campagnes terrain.

### C. Matériel pour les convives (B2C)

- [ ] **3–5 posts types** (stories + carré) : commande, livraison, événements, fidélité.
- [ ] **Storyboard courte vidéo** (15–30 s) : parcours « j’ouvre l’app → je commande ».
- [ ] **Flyer A5 ou A6** : QR + baseline + 1 bénéfice mesurable.
- [ ] **FAQ** : livraison, paiement, compte, réclamations — prête pour le site et le support.

### D. Matériel pour les restaurants (B2B)

- [ ] **One-pager PDF** (1 page) : avantages, tarification ou modèle économique, contact.
- [ ] **Présentation** (10–12 slides) : problème, solution Restafy, fonctionnalités, témoignage, appel à l’action.
- [ ] **Kit onboarding** : e-mail de bienvenue, checklist « mettre à jour menu / horaires / modes de commande ».
- [ ] **Argumentaire téléphonique** ou script WhatsApp pour prospection.

### E. Relations presse et partenaires (optionnel mais fort en crédibilité)

- [ ] **Communiqué de lancement** : qui, quoi, où, pourquoi maintenant, citation, contact presse.
- [ ] **Dossier presse** : 3 paragraphes + 3 visuels HD + logo.
- [ ] **Liste médias / influenceurs locaux** : 10–20 contacts prioritaires avec angle personnalisé.

### F. Lancement et campagnes

- [ ] **Calendrier éditorial** 4 semaines : thèmes par jour/semaine.
- [ ] **Offre de lancement** (si applicable) : durée, conditions, texte légal.
- [ ] **Suivi** : tableau simple (date, canal, objectif, résultat).

### G. Support client et réputation

- [ ] **Numéro / WhatsApp support** affiché et tenu.
- [ ] **Modèles de réponses** : retard de commande, remboursement, bug — validés avec l’équipe produit.
- [ ] **Processus avis** : encourager les avis authentiques (sans achat d’avis).

---

## 3. Alignement avec le produit

- Toute **promesse publique** doit être **vraie dans l’app** (délais, zones, « ouvert maintenant »).
- Les **captures d’écran** marketing doivent être **réactualisées** après les grosses mises à jour UI.
- Coordonnez avec les **Edge Functions / e-mails** (Brevo, etc.) pour que les messages transactionnels reflètent le même ton que la charte.

---

## 4. Prochaine étape concrète

1. Valider les cases **A** (fondations) en une semaine.
2. Publier **un** canal (ex. Instagram) avec **2 posts / semaine** pendant un mois.
3. Imprimer **50 flyers** avec QR pour un test sur **2 restaurants** pilotes et mesurer les scans / inscriptions.
